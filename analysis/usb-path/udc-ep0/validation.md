# EP0 descriptor execution

Two original-cookie EP0 normal descriptors, separate 64-byte packet allocations, actual TinyUSB packetization and class/receive/JBIG output in RAM with independent byte/pixel/event oracles.

50 host; 50 QEMU cases. Exact packet proposals, bytes, retained storage, pixels and document notifications checked.

No physical DCD, SETUP-buffer manager, MMIO, IRQ, cache, boot, USB traffic or printing. CPU/DMA mapping, packet64/BE mode, visibility, immutable observations and settlement remain supplied. IN actual length is separately supplied and never inferred from descriptor low16. Bulk input remains normalized synthetic transport in this experiment; the separate OUT-descriptor suite remains independent. Copies remain metadata and output is synchronous.
