HP LaserJet 1020 Plus — for Apple M-series Macs

INSTALL
Double-click “Install HP LaserJet 1020 Plus.pkg” and follow the installer.
Enter your Mac administrator password when asked. Everything is included:
no extra downloads, Homebrew, repository or Terminal commands.

PRINT
Connect the printer to this Mac by USB and turn it on. If macOS asks to allow
the accessory, choose Allow. Open a document, choose Print, and select
“HP LaserJet 1020 Plus”. Try one page first. Allow extra time after power-on.
Supports A4, US Letter and copies. Your other Mac does not need to stay on.

REMOVE
Open this same disk image and double-click “Remove HP LaserJet 1020 Plus.pkg”.
Finish printing first; removal also deletes this setup's pending and failed jobs.
Other printers are left alone. Deleting the downloaded file does not uninstall it.

IF macOS BLOCKS THE INSTALLER
After trying to open it, go to System Settings > Privacy & Security and choose
Open Anyway for this installer. This private copy is unsigned and not notarized.
Apple's instructions: https://support.apple.com/102445

You can eject the disk image after installation. Keep a copy for removal later.
This packages the working HP-based setup; the new installer has only been checked
offline, so installation and a printed page still need testing. It does not use
the unfinished replacement firmware. Keep this as a private family copy.
